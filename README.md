# Hardware Acceleration Club of KUET (ASP.NET MVC Starter)

Initial implementation includes:

- Introductory homepage (vision, mission, achievements)
- Combined register/login page
- Member projects showcase with comments
- Members-only report/flagging with duplicate suppression window (24h)
- Executives page with contacts
- Faculty advisors page with contacts
- Persistent top-right navigation menu
- Responsive layout and mobile menu
